# Dragon-Escape
Hi there runner!!
This game is about a dragon trying to eat a ball , so the ball tries to escape into a cave ... but guess what? it was the dragon's nest and the cave is falling tooo!!!
This is actually my first game that i ever built (by myself, worked on few games with friends tho) and I built it on my mobile phone using acode (dont have a laptop T_T) ,WHILE learning javascript, so if you have any suggestions or find any bug please let me know!
**Play on :**

## How to play
The game is split into 2 phases
Phase 1 : The Chase
The dragon chases you and your goal is to run while avoiding the fireball it shoots at you ,the rocks that are falling and the spike!!
Phase 2 : The Fight
You reach the end of the cave so now you must throw the golden orbs that are magically falling from the roof out of nowhere at the dragon to kill it and survive!!

## Controls
On mobile : To go Left use ◀ , To go Right use ▶ and to jump use ▲.
On Desktop : Use the arrow keys OR A,D  to move left,right and jump or use space key to jump.
Use [] for full screen.
ON/OFF for mute.
